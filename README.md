# CVRP Quantum-Classical Optimization Benchmark

Implementation and comparison of quantum (QAOA) and classical (Simulated 
Annealing, Genetic Algorithm) methods for the Capacitated Vehicle Routing 
Problem, including heterogeneous vehicle types and time windows.

## Structure
- `classical/` - SA and GA implementation
- `quantum/` - QUBO formulation and QAOA solver
- `data/` - CVRP dataset (Excel)
